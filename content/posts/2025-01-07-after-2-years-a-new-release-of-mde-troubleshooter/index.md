Lately, I’ve been doing a lot of Defender for Endpoint deployment/configuration troubleshooting, which prompted me to dust off my MDE-Troubleshooter. I noticed it was missing some new and improved configurations, so I decided to update it.  
  
What’s new:  
– Updates with the new supported Attack surface reduction rules  
– File hash computation check  
– Run as admin check  
– Option to download the Client Analyzer  
– AV Signature/intelligence updater  
– Overal performance improvements by using different threads  
  
Download: <https://lnkd.in/eDXbhKXF>
