What’s new:  
– Inspired by [Yong Rhee](https://www.linkedin.com/in/yongrhee-msft/) “Resolving High CPU Utilization in MDE” session, added additional options to run the Performance analyzer, Overview is now by default.  
– Added ASR rules that went GA  
– Added a check if DeviceControl is enabled  
– Added Proxy ULR/PAC check  
– Added check to see if signature update are out of date
